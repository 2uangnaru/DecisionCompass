## Translation notes

- Hindi `पश्चिमी सूर्य राशि` in onboarding is deliberately specific: the avatar uses Western Sun-sign dates, not a Vedic moon sign. A native reviewer can shorten it only if that distinction stays clear.
- The Chinese onboarding uses `星座` for that Western Sun-sign avatar, not `生肖` (Chinese zodiac). Keep `时辰` only when discussing possible birth-hour patterns; the actual time input remains a clock time.
- `direction` is metaphorical in both languages. Physical navigation is prohibited; preserve the safety warning in `LEFT/RIGHT` and `FORWARD/BACKWARD` translations when the remaining copy is added.
- Full-sentence luckiest-time headings are in `LUCKY_TIMES_HEADINGS.md`; keep their score caveat visible. Do not translate `52.2%` as a success chance.
